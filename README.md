# All Curls

This is All Curls! It's an ecommerce application created using Next.js and TS with a Firebase backend.

## Getting Started

Navigate [here](https://allcurls-313493779472.us-central1.run.app/) to see the application!

## Usage

- create an account
- login/log out
- add items to cart
- get a subtotal
