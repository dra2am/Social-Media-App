# All Curls

This is All Curls! It's an ecommerce application created using Next.js and TS with a Firebase backend.

## Getting Started

Navigate to [all-curls-ui.com](https://all-curls-ui.herokuapp.com/) to see the application!

## Usage

- create an account
- login/log out
- add items to cart
- get a subtotal
- more to come!
